## Creating the Baselines
<b>Details regarding the creation of the individual baselines can be found in "validation.docx."</b><br>The conslidated baselines were created by Claude:<ul><li><b>Prompt used for union baseline:</b> "Like a researcher, take these baselines and create a 'union' set of information that encompasses all information from each. Make it succinct and accurate."</li><li><b>Prompt used for intersection baseline:</b> "Create an 'intersection' set of information that contains only what is mentioned in all (at least, all excluding the "unspecified" document) the baselines."</li></ul> 

Only the union and intersection baselines are used for validation purposes. The accuracy of the baselines was determined based on inter-agreeability between the baselines and/or the manually extracted data. <br> <br>
<b>Most agreeability/highest-confidence:</b> "PAS_Previa_Intersection_Baselines.docx" (intersection set) <br>
<b>Broadest view of studied mechanisms and biomarkers (/most similar to manually extracted data): </b> "PAS_Previa_Union_Baseline.docx" (Union set)
